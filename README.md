# Formkurve

Persönliches Trainings-Dashboard: Trainingsbelastung (CTL/ATL/Form), eigener Schlafscore, HRV, Ruhepuls und eine tägliche Ruhe- bzw. Trainingsempfehlung. Datenquelle ist intervals.icu, das deine Garmin-Daten automatisch übernimmt.

**Wichtig:** Den API-Key nie ins Repo schreiben. Er wird nur in der App auf deinem Gerät gespeichert.

## Dateien
- `index.html`, `manifest.webmanifest`, `icon-b-180.png`, `icon-b-512.png`: die Web-App
- `formkurve-widget.js`: Homescreen-Widget für die iPhone-App Scriptable
